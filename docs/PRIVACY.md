# Preferred Setup privacy

Preferred Setup keeps your window layout on the computer where Chrome is running. It does not upload layouts, tab addresses, or monitor information. There is no account and no server.

## What it stores

When you save a setup, Chrome stores the window positions, which tab was in front, each tab’s address, whether it was pinned, and — if you leave those options on — tab group names, colors, and zoom. That data stays in Chrome’s local storage for that browser profile. Export writes a JSON file only if you ask for one.

## What it does not do

- It does not read or change the content of the pages in those tabs.
- It does not send the saved setup anywhere.
- It does not sign you in, and it does not include analytics or advertising.
- It does not sell or share data.

## Permissions

- Tabs — to remember each tab’s address and put it back in the same window.
- Tab groups — to restore a group’s name and color.
- Displays — to see which monitors are connected.
- Windows — to open each window where you left it.
- Storage — to keep the layout on this computer.
